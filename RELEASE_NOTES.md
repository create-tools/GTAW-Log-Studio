### Highlights & Core Features

- **Live Memory Engine:** Automatically hooks into the FiveM client process to parse IC, /me, /do, PM, Radio, SMS, and Department logs in real time with zero FPS impact.
- **Storyline Scene Splitter:** Divides long logs into sequential scene cards based on customizable silence gaps (2m, 3m, 5m).
- **Alt-Tab Aware Notifications:** Smart audio chimes sound only when mentioned or PMed while the game window is unfocused.
- **5 Languages Supported:** Full UI localization in English (US), Turkish (TR), Russian (RU), French (FR), and Spanish (ES).
- **Multi-Format Export:** Copy or download as forum-ready BBCode ([color=...]), plain text dialogue, or backup JSON.
- **Integrated Issue Reporter:** In-app feedback modal connected directly to GitHub Issues.
